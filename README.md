# Student Record Management System

A small Python learning project that represents sample student records and demonstrates working with tuples, sets, and frozen sets. It prints examples of collection operations; it is not an interactive record-management application.

## Why this project is useful

- See student details grouped into tuples.
- Use tuple methods to count records and find a student.
- Explore sets for student IDs and courses, including updates, intersections, and symmetric differences.
- Compare mutable sets with immutable frozen sets.

The examples use data defined directly in the script. They do not save records or accept user input.

## Getting started

### Requirements

- Python 3.6 or later

The project uses only Python's standard library; no package installation is required.

### Run the example

Clone the repository and move into its directory:

```bash
git clone https://github.com/VoidLance/course-files-python-student-record-management-system.git
cd course-files-python-student-record-management-system
```

Run the script:

```bash
python3 "Student Record Management System.py"
```

On Windows, use `python` instead of `python3` if that is the command for your Python installation:

```powershell
python "Student Record Management System.py"
```

The program prints the sample student count and index, available courses and IDs, updated IDs, completed and remaining courses, and frozen-set examples. Set contents may appear in a different order between runs.
